# Longboard-Karte

Parawing-/Longboard-Wegekarte Ostalb & Ries als Web-App (GitHub Pages).

- Wegdaten: © OpenStreetMap-Mitwirkende (ODbL), Höhen: Copernicus DEM GLO-30
- Fahrten kommen automatisch aus intervals.icu, Wetter von DWD/Bright Sky bzw. Open-Meteo
- Persönliche Daten (Bewertungen, Fahrten) liegen im privaten Repo `Longboard-Daten`, nie hier.
